# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. All contributors, maintainers, and participants in project spaces are expected to follow it.

## Summary

- Be respectful, constructive, and inclusive.
- Critique ideas and code, not people.
- Do not harass, insult, or discriminate against anyone.
- Do not publish others' private information.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in public threads.

The linked Contributor Covenant text is authoritative; this summary does not replace it.

## Enforcement

Report unacceptable behavior privately to a project maintainer. Maintainers will review reports promptly and confidentially, and may take any action they consider appropriate, including warnings, temporary bans, or permanent removal from project spaces.
